## Recovered p95 scale factors

The app stores speeds as `min(1, hypot(E,N) / p95)`. Because v3 also carries
the raw components, the p95 divisor itself can be solved on uncensored cells —
which means the **normalised speed columns in any export can be returned to raw
units** by multiplying. `spread` is the solve's residual: small means sound.

## Caveats you must read before analysis

- isTectCoastal is the generator TECTONIC class (the old CSV `isCoastal`, js/elevation.js:227-236), not a coastline. isSurfaceCoast is the TRUE land/ocean adjacency coastline, computed here.
- Plate ids are COARSE-mesh seed region ids, not a dense 0..P-1 range.
- pS/pW are p95-clamped (js/precipitation.js:721-724), then interior-capped (:731-739), then contrast-stretched by PRECIP_SEASON_CONTRAST=1 (:745-763) — so they CAN EXCEED 1.0. pS_p95units/pW_p95units are the exact pre-contrast values (the stretch preserves the seasonal mean, so it inverts exactly). pS_censored/pW_censored flag cells whose PRE-CONTRAST value hit the p95 ceiling: sound, but not complete, because the continental interior cap can pull a clamped cell back below the ceiling. Cells with precip_invertible = 0 are not recoverable (the max(0,..) floor at :759-761 broke mean-preservation).
- The layer once exported as `foldRidge` was renamed `phasorRidge` upstream and is emitted under that name. `superPlates` is emitted as the integer column `superPlate`.
- tempSummer/tempWinter/precipSummer/precipWinter in debugLayers are the SAME ARRAY OBJECTS as r_temperature_summer/winter and r_precip_summer/winter (js/planet-worker.js:369-371, 776-778); they are emitted once each, under the short names tS/tW/pS/pW. See aliasedLayers.
- tempContinentality is omitted by the on-demand climate path (js/planet-worker.js:767-780) and therefore only exists on planets small enough for climate at generation time (AUTO_CLIMATE_THRESHOLD = 300000, js/main.js:83). Set CFG.RERUN_WIND + CFG.RERUN_TEMP to recover it.
- coastDistLand, westness and plateContinentality are returned by computeWind (js/wind.js:884-886) but never forwarded by buildClimateFields (js/planet-worker.js:171-193), so they exist in NO stored field. Set CFG.RERUN_WIND to recover them.
- Region 2560000 is the synthetic vertex appended by buildSphere (js/sphere-mesh.js:178-184) at (0,0,1) to close the Fibonacci mesh. Under lat=asin(y)/lon=atan2(x,z) it reports lat 0, lon 0. Its Voronoi cell, neighbour ring, cellArea_km2 and isSurfaceCoast are mesh artefacts, not terrain. Filter isSyntheticPole = 1 before any spatial analysis.
- plateEditDetected = true: the five plate-physics layers were destroyed by a plate-edit rebuild (editDone replaces curData.debugLayers wholesale) and superPlate ids were renumbered by buildSuperPlates. Regenerate the planet from its code and export BEFORE editing to capture them.
- ITCZ curves are a 360-bin RESAMPLING at bin centres over [-pi, pi) (js/wind.js:863-875) of a spline fitted at only NUM_LON = 72 longitudes (js/wind.js:235) — 360 is not the native resolution.

## Not captured in this extract

Debug layers absent (15): `lip`, `phasorRidge`, `uniformNoise`, `dynamicTopo`, `noiseAmp`, `foldBeltWeight`, `cratonWeight`, `basinWeight`, `skeleton`, `continentalDrag`, `sizeVelocity`, `plateSpeed`, `velChange`, `mantleFlow`, `tempContinentality`.

Three distinct causes, do not conflate them:

1. **The live site runs an older build.** Nine layers (`cratonWeight`,
   `basinWeight`, `skeleton`, `noiseAmp`, `foldBeltWeight`, `lip`,
   `uniformNoise`, `dynamicTopo`, `phasorRidge`) exist only upstream. This
   extract captured `foldRidge`, the name that layer had *before* it was
   renamed `phasorRidge` — which is what pins the deployed build as the older
   one. Nothing client-side can recover these.
2. **A plate edit destroyed the plate-physics layers.** `plateSpeed`,
   `continentalDrag`, `sizeVelocity`, `velChange` and `mantleFlow` were wiped
   because `editDone` replaces `curData.debugLayers` wholesale (`plateEditDetected: true` in this extract).
   **Recoverable:** reload the planet from its code and export *before*
   touching any plate.
3. **`tempContinentality` is unreachable on large meshes by design.** It is
   assigned only in the generation path's non-`skipClimate` branch, and this
   planet is above `AUTO_CLIMATE_THRESHOLD`, so climate runs through the
   on-demand path — whose layer set omits it. Recoverable via
   `CFG.RERUN_WIND` + `CFG.RERUN_TEMP`.

Fields reported missing by the exporter:

- coastDistLand
- westness
- plateContinentality
- tempContinentality
- coastDistLand/westness/plateContinentality (CFG.RERUN_WIND is off)
- tempContinentality (omitted by the on-demand climate path; set CFG.RERUN_WIND + CFG.RERUN_TEMP to recover)
