# Life-layer plates

Map plates for the regional ecologies in [`../../docs/life/`](../../docs/life/README.md).
Generated by [`tools/province-ecology/render.mjs`](../../tools/province-ecology/render.mjs)
(zero-dependency Node, using the repository's own PNG writer), from the
corrected v2 export. Province rules are identical to
`tools/province-vectors/main.mjs`, so these plates and
[`../../docs/culture/00_PROVINCE_CONSTRAINT_VECTORS.md`](../../docs/culture/00_PROVINCE_CONSTRAINT_VECTORS.md)
describe the same partition.

Every figure in a plate legend is tallied **per cell over the whole export**,
before any cropping or rasterisation, so the plates agree exactly with
`tools/province-ecology/main.mjs` and with the numbers in the documents (M3
terrain 54.1 / 21.6 / 12.5 / 11.8 %; ecotone 323 / 143 / 272 bins, 43.8 %
mixed). Counting rasterised pixels inside a crop instead would change both the
denominator and the projection weighting.

**One honest edge.** The continent proxy defines Selvana as `lon < -128`, so
V3's plates end on a meridian rather than a coast; the cut is drawn on them in
red and labelled, because it is a definition rather than geography. It drops
1.80 Mkm² of land planet-wide and undercounts Selvana by 1.39 Mkm² against
`reports/tectonics/inventory.json` — see doc 05 §7.

## Regenerating

```sh
node tools/province-ecology/render.mjs            # -> reports/life/maps/
node tools/province-ecology/render.mjs --out DIR --res 0.1
```

The export is a 2.56 M-cell Fibonacci sphere (~14 km spacing, ~0.13° at the
equator), so a raster finer than that leaves unsampled pixels; the renderer
dilates from the sampled pixels to close them. `--res` finer than ~0.05° will
smooth boundaries beyond what the data supports.
